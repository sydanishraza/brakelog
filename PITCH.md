# Tripwire: one-pager

**Problem.** Developers now run coding agents with real credentials and shell access, often unattended. When one misbehaves there is no trustworthy record of what it did and no reliable way to stop it mid-run. A 2026 Kiteworks survey of 459 security and IT leaders found kill-switch capability absent at 79% of organizations. The reported July 2026 OpenAI evaluation escape, which took about a week to connect to a breach, showed the cost of weak visibility.

**Product.** Tripwire is an open-source flight recorder and kill switch for coding agents. Install in minutes, log every action tamper-evidently, block out-of-scope actions, pause with one command.

**Why now.** Agent autonomy is rising faster than controls. Regulators and customers are starting to ask for audit trails and shutdown ability.

**Competition (be realistic).** Funded enterprise vendors already sell runtime agent security, for example Straiker (Agentic Kill Switch, Aug 2026) and Capsule Security ($7M seed, Apr 2026). They are sales-led and aimed at security teams. We are not first.

**Wedge.** Self-serve, developer-first, open source, priced for individuals and small teams, starting with coding agents, and marketed to India's developer and startup community where enterprise tools are poorly served.

**Business model (hypotheses to test).** Free open-source core. Paid hosted layer, roughly $9 to $19 per developer per month: remote hash anchoring, alerts, shared policies, team log search. Later, compliance exports.

**30-day validation.** 150 landing page signups, 15 conversations with agent developers, 3 who say they would pay. If under 50 signups and 0 payers, change the wedge or stop.
